Core Ecommerce

Product catalog, categories, hybrid search, visual search, similar products, recommendations, wishlist, compare, promotions, cart, checkout, Stripe (web Checkout Sessions + mobile PaymentSheet), cash on delivery, order tracking, cancel order with fee/refund eligibility, reviews, newsletter/subscribers, contact, admin operations (including staff QR scan for package/delivery), and store settings.

Orders, QR & Receipts

Secure QR codes for product, order tracking, payment, package, and delivery — resolvable on web and via mobile camera scan / deep links. Customers can cancel eligible orders on web and mobile. Mobile supports reorder-to-cart, payment and order receipt PNG download/share with embedded trackable QR, and Expo push plus an in-app notification center for order and payment alerts.

AI Features

AI helps customers discover products using natural language, images, and voice, while helping administrators automate product content, review analysis, marketing, and business insights. Implemented capabilities include Gemini embedding-based semantic search, hybrid catalog search, similar-product recommendations, visual search (SigLIP/CLIP), web Vapi voice shopping, review sentiment analysis and moderation, AI-generated review replies, AI product content generation, AI email campaign copy, AI Business Copilot with sales and inventory insights, a multi-provider LLM architecture (Gemini, Groq, OpenRouter, OpenAI, Anthropic), and outbound Vapi review calls after delivery.

Mobile App Development

Production-oriented Expo/React Native storefront on the same Convex backend. Navigation: Home → Shop → AI → Cart → Track. Screens and modules include Home, Shop, Search, Categories, Product details, Cart, Checkout (native Stripe PaymentSheet + COD with pending-payment resume), Visual Search, AI Shopping (natural-language hybrid search), QR Scan, Track Order, order detail (cancel, reorder, receipt share), Notifications, Settings with biometric App Lock (Face ID / fingerprint), About, Contact, Newsletter, Wishlist, dark / light / system theme, accessibility, and cache-first offline browsing.

Security & Offline

Optional biometric App Lock is local privacy only (not login or payment auth) and works offline. Cache-first browsing uses NetInfo and AsyncStorage for catalog, products, settings, recently viewed, recent searches, local cart, and wishlist sync. Checkout, Stripe, COD, live tracking, QR resolve, receipt generation, AI, visual search, contact, and newsletter remain online-only. Orders cannot be placed offline.

Cross-platform

React Native and Expo for Android and iOS with EAS builds, shared Convex backend, native Stripe SDK (PaymentSheet; requires EAS/dev build, not Expo Go), iOS camera/photo handling with HEIC/HEIF normalization, Face ID App Lock, push notifications, receipt save/share, safe-area and keyboard handling, and deep links (ecommerce:// / App Links) for QR, Stripe 3DS return, and order flows. Cross-platform and iOS-ready based on implementation and EAS build validation; not claimed as fully tested on every physical iOS device.
